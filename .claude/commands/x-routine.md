# X巡回→DM下書きワークフロー（/x-routine）

このコマンドは `x-check` と `x-dm` を**この順番で連続実行する**ワークフローである。
それぞれの内部ルール（ログイン確認、読み取り専用の制約、DM送信前の1人ずつの確認など）は
一切変更せず、そのまま両方とも遵守すること。このコマンドが変えるのはステップ間のつなぎ方だけである。

## 実行手順

### 1. x-check を実行する

`x-check` スキルの内容をそのまま実行し、レポートを生成して提示する
（`reports/x-check-YYYY-MM-DD.md` として保存されるところまで）。

- ログイン未確認・ログアウト状態などでx-checkが完了できない場合は、その旨をのりあきさんに伝えてこのワークフロー全体を終了する（2へは進まない）。

### 2. 続けて x-dm を実行する

x-check のレポート提示が終わったら、**のりあきさんの追加確認を挟まずに**、
そのまま `x-dm` スキルの内容を実行する。対象レポートは、
たった今ステップ1で生成した最新のレポートを使う。

- x-dm内部の手順（送信済みログの確認、文体の下敷きの読み込み、見込み客ごとの下書き、
  **1人ずつの送信確認**、送信操作、ログ記録）はすべてそのまま従うこと。
  省略してよいのは「x-check→x-dmに進むかどうか」という**ワークフロー間の確認だけ**であり、
  x-dm内の「この人に送っていいか」という確認は絶対に省略しない。
- x-checkの見込み客リストが0件だった場合は、x-dm側の「0件なら終了」ルールに従い、
  その旨を伝えてワークフローを終了する。

## 最後に

両方のステップが終わったら（または途中で終了した場合も）、
x-checkのハイライトと、x-dmで何人に送信・スキップ・送信不可だったかを合わせて簡潔に報告する。
